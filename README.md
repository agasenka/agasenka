## Tentang Saya

Saya **Agas Pratama** (`agasenka`). Sehari-hari saya pakai **NixOS** dengan config flake — karena saya suka sistem yang reproducible dan bisa saya bongkar pasang sendiri. Bahasa utama saya **C/C++**, dan saya tertarik ke arah **systems engineering**, terutama yang berhubungan dengan **DSP** dan **embedded audio**.

Fokus saya ada di **systems programming, low-level optimization, dan real-time audio**. Minat utama saya **DSP pipelines dan embedded audio** — terutama yang berjalan real-time di hardware terbatas. Daily saya menggunakan **NixOS + Niri + Neovim + fish**, dan saya suka mengulik hal-hal yang berjalan dekat dengan hardware, buffer audio, timing, dan bagaimana sebuah sinyal diproses.
